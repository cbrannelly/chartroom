# Inbox

The XO keeps this current. It holds what would otherwise live only in chat: questions waiting on the commander, and approvals given in chat that are not yet written into a task brief. `bearings` reads it. Remove an item once it is answered or recorded in a brief. Add waiting items with `chartroom inbox add --project <project> "<question>"`: each line reads `- [i-xxxx] <date> — [<project>] <question>`, and the stable `[i-xxxx]` id is what the dashboard shows and `/continue <id>` takes.
